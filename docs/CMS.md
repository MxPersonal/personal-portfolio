# Mr.HoSSein CMS Studio | پنل مدیریت اختصاصی

## امکانات

پنل `/admin` دارای چهار تب **مدیریت سایت**، **پروژه‌ها**، **درخواست‌ها** و **تنظیمات** است.

در «مدیریت سایت» همه این موارد مستقل، دوزبانه و قابل انتشار/مخفی‌سازی هستند:

| مجموعه | امکانات |
|---|---|
| بخش‌ها | نمایش/عدم نمایش، تغییر ترتیب Hero, Gallery, About, Services, Projects, Contact |
| متن‌ها | عنوان، معرفی و تصویر Hero، متن About، CTA و Footer و متن‌های ناوبری |
| خانواده خدمات | تغییر عنوان/ترتیب/تعداد ردیف‌های خدمات |
| خدمات و حرفه‌ها | ایجاد، ویرایش، حذف، دسته‌بندی و ترتیب در گروه‌های خدمات |
| مهارت‌ها | عنوان، سطح در JSON تنظیمات، افزودن/حذف |
| رسانه گالری | آپلود تصویر/ویدئو، URL، ترتیب و ردیف اول/دوم |
| شبکه‌های اجتماعی | تغییر، افزودن، حذف و مرتب‌سازی |
| مسیر حرفه‌ای | ویرایش داستان و فصل‌های مسیر توسعه |
| صفحات مستقل | ایجاد مسیر `/fa/page/<slug>` و `/en/page/<slug>`، فارسی/انگلیسی، تصویر و محتوای صفحه |
| پروژه‌ها | فرم تخصصی موجود با عنوان، محتوای فارسی/انگلیسی، لینک، تصویر، وضعیت واقعی و انتشار |
| درخواست‌ها | مشاهده درخواست‌ها و تغییر وضعیت |
| وضعیت همکاری | مقدار فارسی و انگلیسی قابل تغییر |

ظاهر عمومی سایت **بر مبنای قالب اصلی Jack** باقی می‌ماند؛ تغییر ترتیب بخش‌ها فقط پس از انتشار و ذخیره رکورد در CMS روی سایت منعکس می‌شود. تغییر فرم‌های ساختاری و انیمیشن‌ها همچنان کار برنامه‌نویسی است؛ این CMS محتوا و نمایش را مدیریت می‌کند.

## راه‌اندازی، مرحله‌به‌مرحله

1. یک پروژه **ACTIVE و اختصاصی** در Supabase ایجاد یا تعیین کنید. از پروژه‌های نامرتبط برای این سایت استفاده نکنید.
2. فایل `supabase/001_portfolio.sql` را اجرا کنید؛ سپس `supabase/002_cms.sql`.
3. در بخش Supabase Authentication روش **Email OTP / Magic link** را فعال کنید. نشانی `https://personal-portfolio-six-amber-21.vercel.app/admin` را در redirect allowlist قرار دهید.
4. با یک ایمیل مدیریتی وارد سایت شوید. شناسه UUID همان حساب را از **Authentication > Users** بگیرید.
5. پس از بررسی صحیح بودن ایمیل و UUID خودتان، با SQL Editor یک مدیر تعریف کنید:

   ```sql
   insert into public.portfolio_admins(user_id)
   values ('REAL_USER_UUID_HERE')
   on conflict do nothing;
   ```

6. در پروژه **Vercel > Settings > Environment Variables** مقادیر زیر را تنظیم کنید:
   - `VITE_SUPABASE_URL`: نشانی پروژه Supabase (عمومی، مخصوص مرورگر)
   - `VITE_SUPABASE_ANON_KEY`: کلید publishable/anon پروژه (عمومی)
   - `SUPABASE_URL`: نشانی پروژه برای API سمت سرور
   - `SUPABASE_SERVICE_ROLE_KEY`: فقط سمت سرور، برای ذخیره امن درخواست‌ها.
   - اختیاری: `VITE_TURNSTILE_SITE_KEY` و `TURNSTILE_SECRET_KEY`. اگر کلید مخفی را وارد می‌کنید باید چالش کلاینتی متناظر نیز آماده باشد.

   **Service-role هرگز نباید در GitHub، فایل frontend، کلیدهای VITE یا کد مرورگر قرار گیرد.**
7. پس از ثبت متغیرهای Vite باید یک Build جدید از طریق اتصال Git انجام شود تا متغیرهای `VITE_*` وارد خروجی Frontend شوند. روش پروژه: تغییر روی `main` و Deploy خودکار، نه اجرای دستی Deploy.
8. مسیر `/admin` را باز کنید و از طریق **Magic link ایمیل** وارد شوید. بعد از تأیید نقش مدیر، تب «مدیریت سایت» را باز کنید.
9. تنها **یک‌بار** گزینه «راه‌اندازی محتوای قابل ویرایش» را انتخاب کنید. این گزینه محتوای پیش‌فرض سایت را در دیتابیس ثبت می‌کند. در صورتی که جدول پروژه‌ها خالی باشد، سه پروژه شناخته‌شده با وضعیت «در حال توسعه» نیز وارد می‌شوند. پس از آن تمام محتوای قابل ویرایش از دیتابیس خوانده می‌شود.
10. یک متن یا تصویر را ویرایش کنید، «ذخیره تغییرات» را بزنید و صفحه عمومی را Refresh کنید. منتشر/مخفی‌سازی و مرتب‌سازی نیز بلافاصله در نسخه عمومی مبتنی بر CMS تغییر می‌کند و **برای تغییر محتوا هیچ Push یا Build جدیدی نیاز نیست.**

## امنیت

- RLS در `portfolio_projects`, `portfolio_settings`, `portfolio_inquiries` و `portfolio_cms_entries` فعال است.
- کاربران ناشناس فقط رکوردهای منتشرشده را می‌بینند.
- نوشتن، حذف، آپلود و مشاهده داده‌های مدیریتی فقط برای UUID موجود در `portfolio_admins` مجاز است.
- نوشتن درخواست همکاری با کلید محرمانه از مسیر سرور `/api/inquiry` انجام می‌شود؛ مقدار کلید در Browser قابل مشاهده نیست.
- صفحات و لینک‌های CMS باید آدرس معتبر HTTPS یا مسیر داخلی باشند. از افزودن HTML یا اسکریپت شخص ثالث پرهیز کنید.
- تغییر CSS/JS، معماری برنامه و رازهای امنیتی از طریق ویرایش رکوردهای CMS ارائه نمی‌شود.

## محدودیت وضعیت فعلی

کد CMS و فایل‌های SQL داخل مخزن آماده هستند، اما تا زمان اتصال واقعی یک پروژه Supabase فعال و تنظیم متغیرهای Vercel، داشبورد نمی‌تواند به داده‌های آنلاین متصل شود. در این حالت بخش عمومی محتواهای پیش‌فرض را از سورس نمایش می‌دهد.
