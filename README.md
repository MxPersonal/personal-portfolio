# Jack | 3D Creator Portfolio

Responsive 3D creator portfolio built with React, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Development

```bash
npm install
npm run dev
npm run build
```

## Deploy

Vercel: framework Vite, build command `npm run build`, output directory `dist`.

## Assets and placeholders

Add GIFs to `public/work/<name>.gif` to replace the generated marquee tile placeholders. Project buttons and contact links are placeholders pending real destinations. Imagery references `media.promptsites.co` per the original brief.
