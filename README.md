# Mr.HoSSein | Original Template Restored

This version deliberately retains the **original Jack template's layout, section order, colors, scrolling marquee, Framer Motion scroll/entrance animations, and project card composition**.

Changes are limited to real owner profile information: name, FA/EN bio, 15 service types grouped under the original 5-row services component, 8 social links, an owner-sourced portrait, and clearly labelled conceptual/in-progress projects. The original template project imagery is marked as illustrative, not as evidence of completed work. The marquee tiles describe technologies, not claimed client projects.

Run locally: `npm install && npm run dev`; verify: `npm run build`.

Backend and CMS enhancements from the prior redesign remain recoverable in Git history, but **are not part of this original-template-first revision**.
